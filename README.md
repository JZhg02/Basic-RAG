# Basic-RAG
Basic RAG with FAISS and Mistral API

## Create a python env
```
python -m venv venv
```

## Activate environment
```
venv/Scripts/activate
```

## Requirements
```
pip install -r requirements.txt
```

## Run streamlit app
```
python src/app.py
```

## Run main
```
python src/main.py
```
